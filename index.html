Slide Translator

Slide Translator is a Google Slides™ add-on that translates the text of the presentation you currently have open, using Google Translate™.

Features

  • Translates slide text, table cells, and speaker notes
  • Choose to replace the original text with the translation, or display both side by side in bilingual mode
  • Reminds you to make your own copy (File → Make a copy) before translating, so you can keep an untranslated version if you'd like one
  • Simple language dropdown — no typing language codes

How it works

Open a presentation in Google Slides™, launch Slide Translator from the Add-ons menu, choose your target language and translation mode, and run the translation. The add-on only accesses the presentation you currently have open — it does not access any other files in your Google Drive™.
